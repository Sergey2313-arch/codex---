# Sergey Korobkov — Developer Portfolio

Персональное портфолио Junior .NET / ASP.NET Core разработчика.

## Что представлено

- краткая информация обо мне;
- основной технологический стек;
- избранные проекты на ASP.NET Core, Blazor, Razor Pages и React;
- ссылки на исходный код и рабочее демо.

## Избранные проекты

1. **Movies Catalog** — Blazor, .NET 8, Entity Framework Core, SQL Server, QuickGrid.
2. **Contoso University** — ASP.NET Core Razor Pages, EF Core, SQL Server, LINQ.
3. **Movies & Music Search** — React, JavaScript, OMDb API, TheAudioDB API, GitHub Pages.

## Технологии сайта

- HTML5;
- CSS3;
- JavaScript;
- адаптивная вёрстка;
- Intersection Observer для анимаций появления.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.
